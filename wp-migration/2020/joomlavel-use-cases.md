Ok, JoomLavel, allows to integrate Laravel and Joomla but, how does this work? Here are four use cases how to integrate them together.

| complete | **heavy on Joomla** | **heavy on Laravel** | **OpenAPI** |
| --- | --- | --- | --- |
| `JL/LaravelAdapter`<br>rapidly generate Joomla <br>component | `JL/Connect`<br>rapidly generate Joomla <br>component | | `JL/Connect`<br>rapidly generate Joomla <br>component |
| `JL/JoomlaAdapter`<br>rapidly connect Laravel <br>to Joomla DB | | `JL/JoomlaDbLink`<br>rapidly connect Laravel<br>to Joomla DB | |
| `<SETTINGS>`<br>connect api adapter with <br>adapter component | `<SETTINGS>`<br>connect component with<br>remote laravel api | `<SETTINGS>`<br>sync .env with <br>configuration.php | `<SETTINGS>`<br>connect component with <br>remote OpenAPI definied <br>endpoint |
| `<DEV>`<br>enchance both adapter<br>with custom code | | `<DEV>`<br>enchance laravel<br>with custom code | `<DEV>`<br>develope representation <br>by custom code |

_Use Cases for JoomLavel platform_

Every step in the integration process is done with RAD tools for rapid developement. A complete integration of Joomla and Laravel can be done in some minutes. Feel free to contact us if you want to know more.

More info on: http://JoomLavel.io or join us in [github/joomlavel](https://github.com/JoomLavel)
